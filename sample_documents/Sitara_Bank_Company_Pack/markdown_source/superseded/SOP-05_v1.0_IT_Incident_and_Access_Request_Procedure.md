# IT Incident and Access Request Procedure

## 1. Purpose
Applies to: All employees

1.1 This SOP explains how system access is requested and how IT incidents are reported and resolved.

## 2. Access Requests
Applies to: All employees

2.1 System access must be requested by the reporting manager through the IT Service Portal.
2.2 Access requests are normally fulfilled within 3 working days of approval.
2.3 Employees must not use the account of another employee while waiting for their own access.

## 3. Incident Reporting
Applies to: All employees

3.1 Employees must report IT incidents through the IT Service Portal or by calling extension 1100.
3.2 Employees should include screenshots of error messages when reporting an incident.

## 4. Incident Handling
Applies to: IT Support Engineer

4.1 IT Support Engineers must acknowledge Priority 1 incidents within 30 minutes.
4.2 IT Support Engineers must resolve Priority 2 incidents within 8 working hours.
4.3 IT Support Engineers must fulfil approved access requests within 5 working days.
4.4 IT Support Engineers must document the root cause of every Priority 1 incident.
4.5 IT Support Engineers must complete the IT Service Portal administration training within the first week of joining.
4.6 IT Support Engineers may use remote-support tools only after obtaining the consent of the user.
