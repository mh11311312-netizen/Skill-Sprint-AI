# Data Access and Reporting Procedure

## 1. Purpose
Applies to: All employees

1.1 This SOP controls access to production data and the release of management reports.

## 2. Data Access
Applies to: Data Analyst

2.1 Data Analysts must request access to production data sources through the IT Service Portal as described in SOP-05.
2.2 Data Analysts must complete Information Security Basics and Data Privacy Essentials before being granted data access.
2.3 Data Analysts must use only the approved analytics tools listed in the IT Tools Catalogue.

## 3. Report Production
Applies to: Data Analyst

3.1 Every management report must state its data source and extraction date.
3.2 Data Analysts must have each new report peer-reviewed by another analyst before release.
3.3 Data Analysts should automate recurring reports where possible.
3.4 Data Analysts must demonstrate building a masked data extract within 30 days of joining.

## 4. Access Administration
Applies to: IT Support Engineer

4.1 IT Support Engineers must grant data access only after receiving approval from the data owner.
4.2 IT Support Engineers must review all analytics access rights every quarter.

## 5. Oversight
Applies to: Compliance Officer

5.1 Compliance Officers must review a sample of data-access logs every month.
5.2 Compliance Officers may request an ad-hoc access audit at any time.
