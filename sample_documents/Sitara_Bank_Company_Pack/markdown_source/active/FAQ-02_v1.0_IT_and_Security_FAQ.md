# IT and Security FAQ

## 1. How often do I need to change my password?
Applies to: All employees

1.1 You must change your password every 90 days.

## 2. Can I use a USB drive for customer presentations?
Applies to: All employees

2.1 Yes, you may use a personal USB drive for customer presentations if it is scanned by antivirus first.

## 3. What if I forget my password?
Applies to: All employees

3.1 You should reset it using the self-service portal or call extension 1100.

## 4. How do I report a phishing email?
Applies to: All employees

4.1 You must use the Report Phishing button in Outlook.

## 5. When will I get my laptop?
Applies to: All employees

5.1 New joiners receive their laptop and full system access on Day 1.

## 6. Can I install software on my computer?
Applies to: All employees

6.1 You must not install any software without IT approval.
